# Public Information Act request to TDLR

**How to send:** TDLR's media page lists a "TDLR Records Center (open records)" —
https://www.tdlr.texas.gov/media — use the submission method listed there. If you can't
find it, send it through the Customer Service help page: https://www.tdlr.texas.gov/help/
Under the Texas Public Information Act, they may not ask why you want it. If the cost
would be over $40 they must send you a written estimate first — you can decline.

---

**Subject:** Public Information Act Request — Electrician Exam Results by Language

To the TDLR Officer for Public Information:

Under the Texas Public Information Act (Texas Government Code Chapter 552), I request
the following records or data, in any existing electronic format (spreadsheet preferred):

1. For fiscal years 2024, 2025, and 2026 to date: the number of electrician licensing
   exam attempts, passes, and fails, **broken down by exam language (English vs. Spanish)**
   and by exam type (Journeyman NEC, Journeyman Calculations, Master NEC, Master
   Calculations, Residential Wireman).
2. If the above is not kept by TDLR, any report received from PSI (the exam vendor) that
   shows exam volume or pass rates by language.

I do not need any personal information about individual candidates — aggregate counts only.

If any portion is withheld, please release the remainder and tell me which exception applies.
If costs will exceed $40, please send an itemized estimate before proceeding.
